# 🗺️ GeoGuessr СПб — «Петербургский следопыт»

Локальный аналог игры GeoGuessr для Санкт-Петербурга. Вас «высаживают» в случайную
точку города — нужно осмотреться в панораме улиц и угадать на карте, где это.

## 🎮 Как играть

1. Игра выбирает случайную точку в Петербурге и показывает **панораму улиц** Яндекса в этом месте.
2. Осмотритесь и отметьте на карте, где, по вашему мнению, вы находитесь.
3. Чем ближе к реальной точке — тем больше очков (максимум **5000** за раунд).
4. Игра состоит из **5 раундов**, максимальный счёт — **25000**.

### Уровни сложности

Точки генерируются вокруг центра города с разным разбросом:

| Режим | Разброс | Описание |
|-------|---------|----------|
| 🏛️ Центр | ~1.5 км | Исторический центр |
| 🏙️ Средняя | ~3 км | Центр и ближайшие районы |
| 🌆 Весь город | ~6–12 км | От центра до окраин |

Режимы не сравнимы напрямую (в «Центре» угадывать проще), поэтому в таблице
лидеров у каждой записи показан её режим, а саму таблицу можно отфильтровать
по сложности.

### ⏱ Таймер раунда

На старте можно ограничить время на раунд (1 или 3 минуты). Когда время
выходит, ответ отправляется автоматически; если точка не отмечена — раунд
приносит 0 очков. Лимит проверяется и на сервере: опоздавший ответ не
засчитывается. Игры с таймером помечены в таблице лидеров бейджем ⏱.

### ⚔️ Челлендж-ссылки

После завершения игры кнопка «Бросить вызов другу» копирует ссылку вида
`/?challenge=TOKEN`. Открывший её игрок сыграет **те же самые 5 точек** с теми
же настройками, а в конце увидит сравнение своего счёта со счётом автора.

### 🧠 Пул проверенных точек

Каждая найденная игроками панорама сохраняется в пул проверенных точек.
Чем больше сыграно игр, тем чаще новые раунды стартуют мгновенно — с точки,
где панорама гарантированно есть, без перебора случайных мест. Часть точек
по-прежнему генерируется случайно, чтобы пул продолжал расти.

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
cd geoguessr-spb
python3 -m venv venv
source venv/bin/activate  # На Windows: venv\Scripts\activate
pip install -r requirements.txt
```

### 2. Настройка переменных окружения

```bash
cp .env.example .env
```

Отредактируйте `.env`:
- `SECRET_KEY` — секретный ключ Flask (`python3 -c "import secrets; print(secrets.token_hex(32))"`)
- `YANDEX_MAPS_API_KEY` — API-ключ Яндекс.Карт ([developer.tech.yandex.ru](https://developer.tech.yandex.ru/))
- `YANDEX_GEOCODER_API_KEY` — *(необязательно)* ключ HTTP-геокодера — включает адрес точки на экране результата
- `SESSION_COOKIE_SECURE` — `false` для локальной разработки по http (иначе cookie сессии не сохранится)
- `FLASK_DEBUG` — `true` только для локальной отладки
- `DATABASE_URL` — *(необязательно)* URI базы; по умолчанию SQLite-файл в `instance/`

### 3. Запуск приложения

```bash
python app.py
```

Откройте в браузере: [http://localhost:5000](http://localhost:5000)

> Схема БД создаётся и обновляется автоматически при старте (Alembic-миграции
> через Flask-Migrate). Базы, созданные старыми версиями приложения,
> подхватываются и мигрируются без потери данных.

### 🐳 Docker

```bash
cp .env.example .env   # заполнить ключи
docker compose up --build
```

Приложение поднимется на [http://localhost:8000](http://localhost:8000) под
gunicorn; база SQLite хранится на хосте в `./instance/`.

## 🗃️ Миграции БД

Схема управляется Flask-Migrate (Alembic). По умолчанию миграции применяются
автоматически при старте приложения (`AUTO_MIGRATE=true`). Для ручного
управления:

```bash
export FLASK_APP=app.py
flask db upgrade            # применить миграции
flask db migrate -m "..."   # сгенерировать новую после правки models.py
```

При multi-worker запуске gunicorn без `--preload` отключите автомиграции
(`AUTO_MIGRATE=false`) и применяйте их отдельным шагом деплоя.

## 🧪 Тесты

```bash
pip install -r requirements-dev.txt
pytest
```

Тесты используют отдельную временную БД (через `DATABASE_URL`) и не трогают
рабочую базу. Покрыты: расчёт расстояния и очков, валидация координат,
генерация точек, полный проход игры, антифрод (включая реплей cookie),
пул проверенных точек, таймер, челленджи, статистика и лимиты. Тесты
автоматически запускаются в GitHub Actions на каждый push и pull request.

## ⚙️ Технологии

- **Backend**: Python 3, Flask, SQLAlchemy, Flask-Migrate (Alembic), Flask-Limiter, Gunicorn (прод за nginx)
- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Карты**: Яндекс.Карты JS API v3 (карта выбора/результата) + v2 (плеер панорам) + HTTP-геокодер
- **База данных**: SQLite (через `DATABASE_URL` можно заменить на PostgreSQL и т.п.)

## 📝 API Endpoints

| Метод | URL | Описание |
|-------|-----|----------|
| POST | `/api/game/start` | Начать игру (`player_name`, `difficulty`, `time_limit`, `challenge_token`) |
| GET | `/api/game/location` | Координаты текущего раунда для поиска панорамы |
| POST | `/api/game/skip_location` | Перегенерировать точку (если панорамы нет; лимит на раунд) |
| POST | `/api/game/set_actual_point` | Сохранить реальные координаты найденной панорамы |
| POST | `/api/game/guess` | Отправить догадку (`latitude`/`longitude` или `timed_out`) |
| GET | `/api/game/results` | Результаты игры: раунды с координатами, сравнение челленджа |
| GET | `/api/challenge/<token>` | Информация о челлендже для приглашённого игрока |
| GET | `/api/player/stats?name=` | Статистика игрока: игр, лучший и средний счёт |
| GET | `/api/leaderboard` | Таблица лидеров (фильтр `?difficulty=center\|medium\|hard`) |

## 🛡️ Защита от накрутки

- **Состояние игры хранится на сервере.** В cookie клиента — только id игры;
  координаты ответов недоступны ни в cookie (она подписана, но не зашифрована),
  ни в ответах API до завершения раунда. Реплей старой cookie не позволяет
  переиграть раунд.
- **Панорама проверяется по расстоянию.** Реальные координаты панорамы присылает
  клиент, поэтому сервер принимает их, только если они не дальше 1 км от
  сгенерированной им точки. Иначе очки считаются по серверной точке.
- **Серверные лимиты.** Перегенерация точки — не больше 10 раз на раунд
  (нельзя рероллить до знакомого места); создание игр и чтение лидерборда
  ограничены по частоте (Flask-Limiter).
- **Таймер проверяется на сервере.** В игре с лимитом времени опоздавший ответ
  получает 0 очков независимо от поведения клиента.
