# 🗺️ GeoGuessr СПб

Локальный аналог игры GeoGuessr для Санкт-Петербурга. Вас «высаживают» в случайную
точку города — нужно осмотреться в панораме улиц и угадать на карте, где это.

## 🎮 Как играть

1. Игра выбирает случайную точку в Петербурге и показывает **панораму улиц** Яндекса в этом месте.
2. Осмотритесь и отметьте на карте, где, по вашему мнению, вы находитесь.
3. Чем ближе к реальной точке — тем больше очков (максимум **5000** за раунд).
4. Игра состоит из **5 раундов**, максимальный счёт — **25000**.

### Уровни сложности

Точки генерируются вокруг центра города с разным разбросом:

| Режим | Разброс | Описание |
|-------|---------|----------|
| 🏛️ Центр | ~1.5 км | Исторический центр |
| 🏙️ Средняя | ~3 км | Центр и ближайшие районы |
| 🌆 Весь город | ~6–12 км | От центра до окраин |

Режимы не сравнимы напрямую (в «Центре» угадывать проще), поэтому в таблице
лидеров у каждой записи показан её режим, а саму таблицу можно отфильтровать
по сложности.

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
cd geoguessr-spb
python3 -m venv venv
source venv/bin/activate  # На Windows: venv\Scripts\activate
pip install -r requirements.txt
```

### 2. Настройка переменных окружения

```bash
cp .env.example .env
```

Отредактируйте `.env`:
- `SECRET_KEY` — секретный ключ Flask (`python3 -c "import secrets; print(secrets.token_hex(32))"`)
- `YANDEX_MAPS_API_KEY` — API-ключ Яндекс.Карт ([developer.tech.yandex.ru](https://developer.tech.yandex.ru/))
- `SESSION_COOKIE_SECURE` — `false` для локальной разработки по http (иначе cookie сессии не сохранится)
- `FLASK_DEBUG` — `true` только для локальной отладки
- `DATABASE_URL` — *(необязательно)* URI базы; по умолчанию SQLite-файл в `instance/`

### 3. Запуск приложения

```bash
python app.py
```

Откройте в браузере: [http://localhost:5000](http://localhost:5000)

> База данных (таблицы и недостающие колонки) создаётся автоматически при старте —
> отдельный шаг инициализации не нужен.

## 🧪 Тесты

```bash
pip install -r requirements-dev.txt
pytest
```

Тесты используют отдельную временную БД (через `DATABASE_URL`) и не трогают
рабочую базу. Покрыты: расчёт расстояния и очков, валидация координат,
генерация точек, полный проход игры, антифрод и фильтр таблицы лидеров.

## 📁 Структура проекта

```
geoguessr-spb/
├── app.py              # Flask-приложение, API endpoints
├── models.py           # Модели БД (SQLAlchemy)
├── seed_db.py          # (опционально) заполнение БД списком известных мест
├── requirements.txt    # Прод-зависимости
├── requirements-dev.txt# Зависимости для тестов
├── pytest.ini          # Конфиг pytest
├── data/
│   └── locations.json  # Справочный датасет мест СПб (для seed_db, в игре не обязателен)
├── static/
│   ├── css/style.css   # Стили интерфейса
│   ├── js/game.js      # Игровая логика (JS)
│   └── favicons/       # Иконки приложения
├── templates/
│   └── index.html      # Главная страница
└── tests/              # Тесты бэкенда (pytest)
```

> Игра работает на **случайных точках + панорамах Яндекса** и не требует
> заранее заданного списка мест. `data/locations.json` и `seed_db.py` остаются
> как справочный датасет и для возможных будущих режимов.

## ⚙️ Технологии

- **Backend**: Python 3, Flask, SQLAlchemy, Gunicorn (прод за nginx)
- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Карты**: Яндекс.Карты JS API v3 (карта выбора/результата) + v2 (плеер панорам)
- **База данных**: SQLite

## 📝 API Endpoints

| Метод | URL | Описание |
|-------|-----|----------|
| POST | `/api/game/start` | Начать новую игру (`player_name`, `difficulty`) |
| GET | `/api/game/location` | Координаты текущего раунда для поиска панорамы |
| POST | `/api/game/skip_location` | Перегенерировать точку (если панорамы нет) |
| POST | `/api/game/set_actual_point` | Сохранить реальные координаты найденной панорамы |
| POST | `/api/game/guess` | Отправить догадку, получить очки |
| GET | `/api/game/results` | Результаты текущей игры |
| GET | `/api/leaderboard` | Таблица лидеров (фильтр `?difficulty=center\|medium\|hard`) |
| GET | `/api/locations/count` | Кол-во справочных локаций в БД |

## 🛡️ Защита от накрутки

Реальные координаты панорамы присылает клиент, поэтому сервер принимает их,
только если они расположены рядом со сгенерированной им точкой
(не дальше 1 км). Иначе очки считаются по серверной точке, координаты которой
клиент не знает, — это не даёт выдать свою догадку за правильный ответ.
