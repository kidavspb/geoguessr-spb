# Шрифты

Акцентный шрифт проекта — **ALS SPb** (Студия Артемия Лебедева). Он бесплатен
для некоммерческого использования, но не для распространения, поэтому сам файл
`ALS_SPb.woff2` в репозиторий **не входит** (см. `.gitignore`).

Чтобы шрифт заработал в своей копии проекта:

1. Скачайте официальный TTF со страницы шрифта Студии Артемия Лебедева
   (бесплатен для некоммерческих проектов).
2. Сконвертируйте его в woff2 и положите рядом с этим файлом:

   ```bash
   pip install fonttools brotli
   python -c "
   from fontTools.ttLib import TTFont
   f = TTFont('ALS_SPb.ttf')
   f.flavor = 'woff2'
   f.save('static/fonts/ALS_SPb.woff2')
   "
   ```

Без файла ничего не сломается: `font-display: swap` тихо подставит системный
шрифт. ALS SPb используется только для заголовков и крупных цифр, основной
текст и так набран системным шрифтом.
