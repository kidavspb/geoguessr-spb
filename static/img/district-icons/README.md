# Знаки административных районов

18 прозрачных SVG извлечены из переданного для проекта сборного файла
`Иконки районов.svg`. По описанию источника, это знаки с аватаров официальных
групп районов в социальных сетях; сам исходный файл не содержит автора,
ссылки или сведений о лицензии.

Сетка исходника шла построчно в русском алфавитном порядке. Имена файлов
совпадают с canonical district id из `districts.DISTRICT_IDS`. При извлечении
удалены белые плитки и служебные элементы макета, а каждому знаку задан
квадратный tight `viewBox` с одинаковым оптическим полем. Исходный цвет
`#2FC6F5` сохранён.

Перед использованием этих знаков вне проекта следует отдельно проверить
право на их распространение.
