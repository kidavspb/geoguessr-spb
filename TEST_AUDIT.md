  умолчанию для старых workers. Создание схемы через модели их не заменяет.

  контракты данных; статическая проверка сама по себе не повод для удаления.
- Конкурентные запросы и повторные запросы: разные риски транзакций и сети.
- Локальное исчерпание поиска и HTTP 429: разные ветви восстановления.
- Backend-валидация панорам и E2E с подменённым ответом валидации: E2E проверяет
  реакцию клиента, а не правильность серверной географии.

  геометрия и touch: отдельные сценарии с подтверждённой историей исправлений.
